# 등대지기 곰

등대지기 곰이 밤이 끝나기 전에 갈매기를 피해 꺼진 등불을 모두 켠다. (GAME_DESIGN.md 1장)

## 여는 법

- GitHub Pages: https://terimu.github.io/dotgame-leetaerim/
- 로컬 실행: 저장소 폴더에서 `python3 -m http.server 8000`을 실행하고 http://localhost:8000 을 연다. `index.html`을 `file://`로 직접 열면 ES module이 막혀 실행되지 않는다.

## 조작

- 방향키: 한 번 누르면 한 칸 이동한다.
- 스페이스바: 등불 켜기, 시작, 실패·엔딩 뒤 처음 화면(타이틀)으로 돌아가기.

## 규칙 요약 (GAME_DESIGN.md 2장)

- 레벨은 3개이고 순서는 레벨 1(9×7) → 2(10×7) → 3(11×9)이다. 레벨 3을 클리어하면 엔딩이다.
- 곰이 등불(`L`) 칸에서 스페이스바를 누르면 그 등불이 켜진다. 레벨의 등불을 모두 켜면 클리어다. 등불은 레벨 1이 3개, 레벨 2가 4개, 레벨 3이 5개다.
- 제한시간은 레벨마다 60초이고, 다음 레벨에서 60초로 다시 시작한다. 시간이 지나면 실패이고 타이틀을 거쳐 레벨 1부터 다시 시작한다(점수 0).
- 갈매기는 300 ms마다 한 칸씩 곰 쪽으로 다가온다. 곰과 같은 칸이 되면 곰이 3초(3 000 ms) 기절해 그동안 입력이 무시된다. 기절에는 감점이 없다.
- 점수는 레벨을 넘어 이어진다.
  - 새로 켠 등불 하나에 +100점.
  - 클리어하면 남은 시간(초, 내림) × 10점을 더한다.
  - 한 판 점수는 1200점 + 레벨별 클리어 보너스 합이고 3000점 이하다. 모두 경과 1 ms에 깨면 2970점, 모두 정확히 60 000 ms에 깨면 1200점이다.
  - 실패 점수는 이전 레벨까지의 합에 현재 레벨에서 켠 등불 × 100을 더한 값이다.

## 레벨 한 개 추가하는 법

1. GAME_DESIGN.md 5장에 격자를 추가한다.
2. `src/levels.js`에 같은 글자로 배열을 추가하고 `LEVELS`에 넣는다.
3. GAME_DESIGN.md 9장에 수용 기준을 추가한다.
4. `node --test test/`를 실행한다.

## 테스트 실행

```
node --test test/
```

## 효과음·최고 점수·타이틀·글자 (GAME_DESIGN.md 3·4·7장)

- 타이틀: 이름 "등대지기 곰"(색 5, 40 px)과 그 아래 "스페이스바로 시작"은 웹폰트 글자다.
- 글자: HUD·타이틀·엔딩·실패의 모든 글자는 도트 웹폰트 Galmuri9(`fonts/Galmuri9.woff2`, 라이선스 `fonts/OFL.txt`, SIL OFL 1.1)로 20 px(타이틀 이름 40 px)에 그리고, 반투명 가장자리는 정리해 도트처럼 보이게 한다. 다른 폰트·이미지·오디오 파일은 없다. 배치 숫자는 GAME_DESIGN.md 7장이다.
- 효과음 5종(엔딩·실패·레벨 1·2 클리어·기절 시작·새 등불 점등)은 Web Audio로 합성하고 오디오 파일·배경음악은 없다. 첫 키 입력 뒤부터 소리가 난다. 음 수치는 7장 표다.
- 최고 점수: 엔딩에 들어갈 때 한 번, 판 점수가 더 클 때만 localStorage 키 `lighthouse-bear-best` 하나에 저장하고 엔딩에 `최고 점수 n`으로 보인다. 실패 판은 저장·표시하지 않는다.
