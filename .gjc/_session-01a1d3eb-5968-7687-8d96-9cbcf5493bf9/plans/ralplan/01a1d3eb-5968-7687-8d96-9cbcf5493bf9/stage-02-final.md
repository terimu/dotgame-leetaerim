- 글꼴: HUD·엔딩·실패는 브라우저 기본 monospace 16 px 유지, 웹폰트 미사용(이번 요청이 폰트를 금지하고 R2에서 읽힘이 확인됨).
- 오디오: `src/sound.js`가 OscillatorNode+GainNode로 7장 표를 합성. AudioContext는 첫 keydown(사용자 제스처)에서 만들고 `suspended`면 `resume()`. 생성 실패·미지원이면 소리 없이 게임은 계속된다.
- 최고 점수: 키 `lighthouse-bear-best`(이 게임이 만드는 localStorage 키는 이것 하나), 값은 0 이상 3000 이하 정수 십진 문자열(`BEST_SCORE_MAX=3000`은 logic.js 상수). 읽기 `parseBestScore`: 값 없음·정수 문자열 아님(앞자리 0·부호·소수·지수 불가)·3000 초과는 0. 갱신: 엔딩 또는 실패로 들어가는 순간 한 번, 판 점수가 현재 최고보다 클 때만 `nextBest` 후 저장. 최고 점수는 game 상태가 아니라 main.js 변수라 새 판에도 유지. `src/storage.js`는 `localStorage` **접근 평가 자체**(접근자 함수)·getItem·setItem을 모두 try 안에서 하고, 어느 하나라도 예외를 던지면 조용히 건너뛰며(읽기는 0, 저장은 무동작) 최고 점수는 이번 방문 메모리에서만 유지한다. main.js는 `localStorage`를 최상위에서 참조하지 않는다.
- 외부 파일 없음: 오디오·이미지·폰트 요청 없음(브라우저가 자동 요청하는 favicon 제외, index.html에 아이콘 링크를 추가하지 않는다). 숫자 상수(60 000, 3 000, 300, 100, 20261113, 100점, 10점, 3000)는 logic.js 한 곳, 효과음 수치는 sound.js 한 곳, 타이틀 배치 수치는 sprites.js 한 곳.
- 탭 비활성 한계: 탭이 비활성이면 rAF가 멈추고 시계는 흐르므로 복귀한 첫 프레임에 밀린 갈매기 이동·기절·만료가 한꺼번에 처리돼 곧바로 기절·실패할 수 있다. R3도 일시정지를 만들지 않는다(10장). 이때 소리는 프레임당 우선순위 최고 하나.

## 12. ADR 초안
- **Decision**: design-v3(문서만, 기계적 게이트 4개와 5음절 판독 게이트) → goal-4(levels.js 2개, 로직 무변경, 테스트 교체·추가) → goal-5(상태 비교 `soundEvent`, logic 순수 `parseBestScore`/`nextBest`, 얇은 sound.js·storage.js, 16×16 도트 타이틀). 9장 1~35번은 불변이고 주석 표로 한정, 옛 레벨 전환 소비 항목은 확인 범위로 이동.
- **Drivers**: 문서-코드 일치, 기존 테스트·순수성 유지, 사람 확인 가능성.
- **Alternatives**: 문서 쪼개기(v3a/b), goal 연속 실행, 이벤트 배열 반환, logic.js 주입식 저장 래퍼, 한 장 타이틀 스프라이트, 타이틀 안내 B(키 그림 + monospace 글자 유지)·C(키캡 안 도트 한글: 음절 8개 추가, 키 폭 재설계) — A 채택은 사용자 확정.
- **Why chosen**: tick이 이미 레벨 전환·합산·리셋·소비를 처리하므로 goal-4는 데이터와 테스트만 바꾼다. 상태 비교는 logic 시그니처와 기존 65개 테스트를 건드리지 않는다. storage 분리는 순수 규칙 파일에 try/catch 부수효과를 두지 않기 위함이며 접근 예외까지 node에서 테스트하게 한다.
- **Consequences**: LEVELS 3개로 기존 엔딩 테스트 5곳 교체 필요, goal-5가 파일 8개, 탭 비활성 한계 잔존, 소리는 사람이 귀로만 확인, image-rendering이 글자 모양에 영향을 줄 수 있음.
- **Follow-ups**: 5음절 도트 모양은 design-v3 diff에서 조정, 효과음은 귀로 듣고 조정, 일시정지가 필요하면 새 라운드에서 기획.
